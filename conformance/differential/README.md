# Differential testing

moiety's own suite and round-trip corpus were written against the same reading of the grammar as the parser, so they share its blind spots. Differential testing runs the same inputs through an independent implementation and treats every disagreement as a case to judge, not as a failure.

The comparison here is against the condensed-formula expander in [MolScribe](https://github.com/thomas0809/MolScribe) (MIT), pinned to commit `7296a30413eb55436702011efdff78131f66d162`.

## What is compared

MolScribe expands the text labels it finds in chemical images, so its expander only reads **substituent labels**: a label with one bond to the parent structure, such as `CO2Et` or `N(CH3)2`. It cannot read a complete molecule such as `CH3CH2OH`. The corpus is therefore 246 labels in [labels.txt](labels.txt), each marked with the side its bond is on:

- `left` for labels written from the attachment, such as `CH2OH`. moiety reads `-CH2OH`.
- `right` for labels written toward it, such as `HOOC`. moiety reads `HOOC-`.

MolScribe reads each label with one single bond to the parent, choosing its own reading direction as it does in practice. The harness puts a `*` on the atom that carries that bond and canonicalizes with RDKit. moiety then canonicalizes both sides with its own SMILES writer before comparing.

## Files

| File | Contents |
| --- | --- |
| [labels.txt](labels.txt) | The label corpus |
| [molscribe.toml](molscribe.toml) | MolScribe's results, generated by the harness |
| [adjudications.toml](adjudications.toml) | A verdict and reason for every disagreement |
| [report.toml](report.toml) | Every label that is not an exact match, with both results and the verdict |

## Results

| Outcome | Labels | Meaning |
| --- | --- | --- |
| same | 182 | MolScribe's result is moiety's rank 1 reading |
| alternative | 16 | MolScribe's result is one of moiety's lower-ranked readings |
| different | 16 | Both read the label, to different molecules |
| moiety-refuses | 2 | moiety reports no reading, MolScribe gives one |
| other-fails | 29 | moiety reads the label, MolScribe does not |
| both-fail | 1 | Neither reads the label |

Every one of the 34 labels that needs a verdict has one, and none is decided against moiety:

- **moiety right (18).** MolScribe turns acyl groups such as `COCH3`, `NHCOCH3` and `MeO2C` into carbon radicals with the oxygen as a chain link. It reads `NCO` and `NCS` as cyanate and thiocyanate instead of isocyanate and isothiocyanate, and it reads `sBu` as n-butyl. It also guesses n-propyl and n-butyl for `C3H7` and `C4H9`, which moiety reports as underdetermined.
- **Both defensible (16).** A trailing dash after a heteroatom, as in `HO-` or `AcO-`, is a charge or an open valence. moiety ranks the anion first and lists MolScribe's group reading second. `SOCH3` is methylsulfinyl or a sulfenate ester; moiety lists both.

The comparison found three moiety bugs, now fixed and covered by conformance cases under `differential/`. `CF2H` had no reading, `C2F5` was refused as a molecular formula, and a written charge could not land inside a repeated group, so `CH3(CH2)3-` was wrongly unique. It also led to ranking policy 2, which ranks the acetyl reading of `CH3CO-` above the acyl anion.

## Rerunning

The comparison itself needs only moiety, so CI checks the recorded results on every push (`crates/moiety/tests/differential.rs`). Regenerating MolScribe's results needs Python, RDKit and a MolScribe checkout:

```text
git clone https://github.com/thomas0809/MolScribe.git /tmp/molscribe
git -C /tmp/molscribe checkout 7296a30413eb55436702011efdff78131f66d162
python -m venv /tmp/venv && /tmp/venv/bin/pip install rdkit==2026.9.1
/tmp/venv/bin/python -I conformance/tools/molscribe_labels.py /tmp/molscribe conformance/differential/labels.txt conformance/differential/molscribe.toml
moiety differential conformance/differential/molscribe.toml -o conformance/differential/report.toml
```

`moiety differential` exits non-zero while any disagreement lacks a verdict. A verdict of `other` records a moiety bug; the test fails until it is fixed.
